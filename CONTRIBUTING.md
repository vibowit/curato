# Contributing & Community

Thank you for your interest in Curato!

### Project Status & Scope

Curato is a personal, bespoke portfolio project engineered specifically for single-user operation in a private homelab environment (Proxmox VE / LXC). It is tailored to personal taste profiling, custom AI assistants (Antigravity & ChatGPT via Model Context Protocol), and a private Simkl account.

### Issues and Pull Requests

Because this project is maintained for personal use and showcase purposes:
- **GitHub Issues and Pull Requests are disabled.**
- Formal bug trackers and unsolicited code contributions will not be tracked or merged here.

### Questions, Feedback & GitHub Discussions

If you have questions about the architecture, want to share ideas, or discuss integrations (such as Model Context Protocol, SSE reverse proxying, or Simkl API workflows):
- **Please use [GitHub Discussions](https://github.com/vibowit/curato/discussions)**!
- We welcome constructive questions, homelab setup discussions, and general feedback.

### Forking and Customization

You are warmly encouraged to **fork** this repository under the terms of the [MIT License](LICENSE) and customize it for your own library, preferred streaming trackers, and AI providers.
